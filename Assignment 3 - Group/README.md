# Assignment 3: Mini research report

Deadline: November 8, 2026 at 23:59 Europe/Copenhagen.

Formulate and test a focused hypothesis or research question connected to one or more curated course papers. The question should not be directly answered in the existing literature and should stay narrow enough to execute within the course time and resource limits.

The published Canvas page explicitly allows the project to draw on the final topic's materials, even though that topic is not part of the student-presentation rotation.

Requirements:

- Use the ISBI LaTeX template in `../ISBI Template/`.
- Maximum 4 pages, excluding references, figures, and tables.
- Submit a PDF through Absalon.
- State the group number, all members, and the most relevant baseline or curated paper.
- Describe every member's concrete contribution and initial idea or plan. Do not write only "equal contribution".
- Include a link to the assignment's GitHub repository.
- Figures and methodological illustrations should primarily be original.

Suggested report structure from the published Canvas specification:

- Abstract
- Introduction and hypothesis/contributions
- Background or related work
- Methods
- Experiments and results
- Conclusion and discussion
