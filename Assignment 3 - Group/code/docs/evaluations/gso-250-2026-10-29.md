Results are in progress, not a completed benchmark or a method ranking.

The run stores selection.json, config.json, source-sha256.json, data/manifest.jsonl,
data/visibility/, logs/, and separate results/sam3d, results/mvsam3d and
results/stream3d folders. Each result folder has evaluation.jsonl, progress.json,
runtime.json, and per-object inputs, exact meshes, coarse occupancy, latents,
pointmaps, geometry metrics, alignment transforms, error maps and resource data.
Completed object records are atomic and resumable under the same protocol.

Selection: exactly 250 unique objects from the official 1,030-object GSO source,
Python random.Random(42).sample over sorted downloaded object names. Selection
SHA256: `e70f5c0301eefec9f3f51cda88469cb063d7bfac9918292698fdae1ca41ebc52`.

Inputs: existing 32-frame, 384px isolated-object renders from the dataset preparation
task. No duplicate GSO rendering was performed. Frames [0,10,21,31] are fixed for
every object and shared across methods; native SAM 3D receives frame 0 only.
Each method uses 25 flow steps per stage and matched sample-keyed seeds. Stream3D
uses chunk size 2 and top-k 4, so this protocol exercises memory updates without
compressing a four-view clip. The integrations use MoGe, not the papers' DA3
preprocessing, and omit Stream3D's separate Stage-2 selector/diversity re-ranking.

GT visibility uses 8,192 area-uniform surface samples per object, seed 43,
registered render cameras and first-hit ray queries. Each shared cache records
mesh/camera hashes and frame IDs. Visibility partitions mean self-occlusion and
additional-view coverage, not occlusion by other objects. These cached labels
are independent of model predictions.

Validation before submission: all 250 selected objects, 8,000 RGB/mask pairs and
occupancy files passed the input audit. Visibility caching finished successfully.
All ten focused integration tests passed on UCloud, including native BVH nearest
surface queries, visibility partition/cache provenance, exact mesh export,
native reference selection and reuse of the shared evaluator. All 34 source
file hashes matched the local source delta. CPU cache batch 12439127 exited zero
and reached provider SUCCESS, releasing its allocation.

All shared generated-geometry metrics are saved: canonical/aligned voxel IoU,
surface-voxel Chamfer, F-score thresholds, empty flags and region-specific
canonical completeness/recall. Refined-mesh metrics use sampled exact
closest-triangle queries in raw and similarity-aligned frames. Flow loss is
explicitly null/not-computed because this runner does not define a matched
multi-view training-loss objective; this is distinct from the earlier adapter
flow-loss comparisons.

Each GPU job foreground entrypoint runs installation, verification, reconstruction,
all metrics and final output validation. Exit ends its dedicated allocation on
success or failure; a ten-hour provider limit is the fallback. Persistent logs
and exit-code JSON distinguish application failure from provider lifecycle status.
Old B200 job 12439107 was stopped by the dataset task after a newer direct user
instruction there; these evaluations do not reuse or restart it.

Startup verification: SAM 3D job 12439137 has completed at least ten full object
records. Every checked record includes voxel metrics, visibility metrics,
refined-mesh metrics, all registered geometry artifacts, saved surface-error
arrays and nonzero metric timing. The persistent first-record-validation.json
records this check. The other two jobs were queued at this check; submission
does not establish that those full 250-object runs have finished.
