The merge is implemented on `unify-video-pipeline`. All checks ran remotely on Linux;
training and rendering used an NVIDIA L40S. Python 3.11.5, Torch 2.7.1 + CUDA 12.8.

The CPU suite's GPU and dataset-dependent cases were exercised separately above. Shellcheck
was unavailable in the remote image; shell files passed `bash -n` and the portable shell
runner passed its integration test.

Each real model case used two optimizer updates, saving after update one and resuming in
a fresh model instance. Both EMA adapter and optional LoRA states were reloaded for evaluation.
These are correctness smoke runs, not convergence or model-quality experiments. The common
sampler used one shortcut step and evaluation metrics ran on CPU. The GPU suite additionally
checked encoder token order/counts, conditioning determinism, adapter identity, conditioning
gradients, null/layout behavior, VAE reconstruction and frame conventions.

The native loss comparison produced **0.23598560690879822** for both implementations, with
matching conditioning gradients. The quick reference check is `tests/test_loss_parity.py`;
the source path and pinned upstream commit are recorded beneath the production loss.

The rendering fixture uses four 128×128 frames and two Cycles samples. This Modal worker
could not create an OptiX denoiser, so the smoke fixture explicitly uses the existing `INTEL`
denoiser option. Rendering still used the GPU. The production generator defaults and
rendering/sampling algorithms are retained. A smooth procedural background keeps this small
fixture within the generator's existing JPEG quality contract; the PSNR threshold was not changed.

Verification fixed GPU RNG restoration after CUDA checkpoint loading, the fusion adapter's
half-precision input boundary, and V-JEPA wheel packaging (`src` and `app`). It also corrected
two inherited test assumptions: configured video dimensions replace fixed dimensions in export
tests; token order is checked before self-attention, where locality is exact.

`atdl-unified-verification` volume. Dedicated workers exit after their bounded checks.
