\section{Comparison of experimental settings}\label{app:protocol}
Table~\ref{tab:protocol} compares the completed vision experiments one
setting at a time. Page numbers refer to the 2021 journal article
(32 pages), not an earlier arXiv version~\cite{nakkiran2021deepdouble}.
Released code paths refer to commit
\href{https://gitlab.com/harvard-machine-learning/double-descent/-/tree/0d653296f870e6bf7ee82dc71b4f7b49d53fa85d}{\texttt{0d653296}}.
The release contains model definitions, plotting notebooks, and a
\href{https://gitlab.com/harvard-machine-learning/double-descent/-/blob/0d653296f870e6bf7ee82dc71b4f7b49d53fa85d/README.md}{\texttt{README.md}}
linking result archives; it does not provide the vision training loop or
data loader. Where neither the paper nor those files specify a detail,
we identify it as unstated rather than infer a setting from the results.
